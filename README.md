# PBC Update

여러 Excel 조서의 원본 데이터와 공통 설정을 일괄 갱신하는 조서 작성 지원 프로그램입니다.

## 배포 버전

**1.6.2 · 본인 실무 사용 중**

**[실행파일 다운로드](PBC_Update_v1_6_2.exe?raw=true)** · [사용 안내](USAGE.md)


## 주요 기능

- 같은 이름의 원본·대상 시트를 찾아 기존 탭을 유지하는 복사·붙여넣기 방식으로 갱신
- 어떤 대상 조서에도 없는 원본 탭 확인 및 선택한 조서에 삽입
- 결산일·회사명·Benchmark·OM·PM·DM 등 공통 값·수식 설정
- 회계기간과 작업일에 따른 파일명 갱신
- 작업 전 기존 파일 자동 백업

## 설계 이유

여러 회사와 감사기간의 조서에서 반복되는 원본 데이터 교체 작업을 줄이기 위해 만들었습니다. 기존 탭을 유지하는 방식으로 최초에 설정한 셀 참조와 XLOOKUP 등의 조회 수식을 활용하고, 새 명세서는 삽입할 조서를 선택하도록 구성했습니다.

## 사용 경험

2026년 4월부터 분·반기 및 중간감사, 6월 말 결산법인 관련 조서 작업에 지속적으로 사용 중 입니다.

업무 숙련도 향상 효과를 배제할 수는 없지만, 해당 프로그램을 사용하며 조서 작성 시작부터 완료까지 걸리는 시간이 크게 줄은 것을 체감했습니다.

## 데이터 처리 방식

정보 유출 우려를 고려해 업무 데이터를 외부 LLM에 전송하지 않는 구조로 설계했습니다. 개발에는 AI를 활용했지만, 실제 처리에는 구현된 규칙과 수식·참조 관계를 사용합니다.
